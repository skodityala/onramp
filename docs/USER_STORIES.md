# User stories

Written in "As a X, I want Y, so that Z" format. Each maps to a specific decision made in the product.

## Primary user: the neurodivergent student

As a 15-year-old with ADHD, I want to see one physical action instead of the whole assignment, so that I can begin without having to plan.

As a student with executive dysfunction, I want the first step to be startable in under two minutes, so that I do not have to negotiate with my own hesitation.

As a dyslexic student, I want an "extra spacing" toggle, so that the text is easier for me to parse.

As a student who has been called lazy for years, I want a tool that does not congratulate me or grade me, so that I stop associating "help" with "being evaluated."

As a student who is easily overwhelmed, I want a tool that refuses to show a progress bar, so that I cannot see how much remains.

As a student mid-sentence, I want the tool to notice that I have started but not advance me, so that my work is not destroyed.

As a student who has finished a session, I want the tool to say "you started N times" and nothing else, so that a plain fact is what I leave with.

## The parent

As a parent, I want to send my child a link that lands them on the first step, so that I do not have to nag them into opening a tool.

As a parent, I want the tool to work without a signup, so that a stuck child does not face another form to fill in.

As a parent, I want the tool to store nothing about my child on any server, so that their schoolwork is their business.

## The teacher

As a teacher, I want a tool that respects my student's autonomy, so that I am not surveilling them.

As a teacher, I want a tool with no dashboard for me, so that my student trusts me to use it.

As a teacher, I want to be able to demo the tool in class in 30 seconds without a login, so that students see value before they lose interest.

## The support worker

As a support worker, I want to open the tool on my phone with no setup, so that I can help a student in front of me right now.

As a support worker, I want a share link I can text or email to a student, so that the tool works after they leave my office.

As a support worker, I want the tool's reasoning to be inspectable, so that I can explain to a family whether it might help.

## The adult self-user

As an adult with executive dysfunction, I want a tool that does not evaluate me, so that I stop associating "productivity apps" with shame.

As an adult, I want to press Smaller as many times as I need, so that I never hit a wall where the tool tells me to try harder.

As a user with vestibular sensitivity, I want all animation to be under 250ms and to stop entirely under prefers-reduced-motion, so that using the tool does not physically hurt.

## The clinician

As a clinician, I want the tool's decisions to be deterministic and unit-tested, so that I can tell a family what to expect.

As a clinician, I want the tool to refuse to make clinical claims, so that my patients are not being misled.

As a clinician, I want the tool to not require an account, so that my patients' data stays with them.

## The contributor

As a contributor, I want the checker to be deterministic and covered by 108 test cases, so that I can add a template without fearing regression.

As a contributor, I want a clear list of banned words enforced by test, so that I do not accidentally reintroduce praise language.

As a contributor, I want to be told explicitly which features are refused, so that I do not waste time proposing them.

As a contributor, I want to know exactly what "adding a template" involves, so that I can help without needing a design meeting.

## The judge

As a hackathon judge, I want to clone and run the app in two commands without an API key, so that I see the product in the first minute.

As a hackathon judge, I want the tests to pass offline, so that I can verify the claim of "no backend required."

As a hackathon judge, I want the README to be substantive, so that I can score the submission without opening every source file.

As a hackathon judge who is neurodivergent myself, I want the design to be a considered refusal of gamification, so that I can trust the team understands the audience.
